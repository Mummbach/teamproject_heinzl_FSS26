# 📂 Data Setup — MIMIC-IV

## Access

MIMIC-IV is a restricted dataset. To use it:

1. Create an account at [PhysioNet](https://physionet.org/)
2. Complete the required CITI training course
3. Apply for access to [MIMIC-IV v3.1](https://physionet.org/content/mimiciv/3.1/)
4. Once approved, download via `wget` using your PhysioNet credentials:

```bash
wget -r -N -c -np --user Mummbach --ask-password \
  https://physionet.org/files/mimiciv/3.1/ -P data/raw/
```
